## 💼 How to Create Sea Freight Shipment

### **In Admin Dashboard:**

1. Click "Create Shipment"
2. Enter sender/receiver details
3. **Important Fields:**
   - **Third-Party Tracking Number:** Enter B/L number here
   - **Mode:** Select "Sea Freight"
   - **Service Type:** FCL/LCL/Break Bulk
   - **Origin:** Port name (e.g., Shanghai Port, China)
   - **Destination:** Port name (e.g., Mombasa Port, Kenya)
4. Enter package details (weight, CBM, value)
5. Click "Create"

**System automatically:**
- Generates unique tracking number
- Stores B/L number
- Sends emails to sender & receiver
- Creates tracking timeline
