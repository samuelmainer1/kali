Local dashboard only
====================

Open: http://127.0.0.1:5173/admin
This is the Globeflight admin dashboard, including Tracking.

The passwords are the ones set for this copy. They are not written in this file
because the repository is public. The old LocalAdmin2026 password no longer works.
These details do not sign you in at https://globeflight.co.ke/admin.

Edits are saved in server/data/db.json and show up on the local site
(tracking, blog, services, jobs, categories, and testimonials).
Accounts are saved in server/data/auth.json.

A sample shipment is included so tracking can be tried immediately:
  Number: GF20261001
  Page:   http://127.0.0.1:5173/track?trackingNumber=GF20261001

Email
  Replies and new-message notices are sent when RESEND_API_KEY is set
  in the server environment. The key stays out of this public repository.
  See .env.example. Until that key is set, a reply is saved and the
  dashboard says the email was not sent.

Live chat
  The public site has a chat button at the bottom right. A visitor enters
  an email and phone number before the chat starts. Those details are
  saved under Live chat contacts in the dashboard menu, and they also
  show in the chat itself. They are emailed to cs@globeflight.co.ke when
  RESEND_API_KEY is set. While an admin is signed in to this dashboard,
  that person answers. When nobody is signed in, the assistant answers
  if GROQ_API_KEY is set in .env. The assistant answers basic questions
  from the services and offices published on the website. It does not
  give prices or look up a shipment. Quotes and inquiries in the chat
  use sam.maina@globeflight.co.ke. The key stays out of this public
  repository.

Start the API before the dashboard:

  cd Globeflight-Kenya
  npm run server
  npm run dev -- --host 127.0.0.1 --port 5173
