# Module 13 — Sales Pipeline

## Scope (v1)

- Opportunity stages: New Lead → Contacted → Quotation → Negotiation → Won / Lost
- Sales see own deals; management sees all + performance
- Optional linked quotation; follow-up dates; lost reason
- Dashboard pipeline summary (announcements stay in header bell only)
- No commissions in v1

## Permissions

| Permission | Use |
| --- | --- |
| `pipeline.view` | Sales own opportunities |
| `pipeline.manage` | Create / update / move stage |
| `pipeline.view_all` | Management/admin see everyone |
