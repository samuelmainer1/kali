# Module 14 — Procurement & Expense Requests

## Scope (v1)

- Any employee can submit a purchase request with line items
- Flow: Submitted → Approved/Rejected → Processed (finance)
- Management visibility: pending, approved, monthly spend
- No vendor catalog / GRN / accounting export yet

## Permissions

| Permission | Use |
| --- | --- |
| *(staff role)* / `procurement.request` | Create and view own requests |
| `procurement.approve` | Manager/admin approve or reject |
| `procurement.process` | Finance mark as processed |
| `procurement.view_all` | See all company requests |
